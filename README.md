# آکادمی پرچم | Flag Academy

این مخزن **مرجع رسمی (Source of Truth)** تصمیم‌های قطعی آکادمی پرچم است.

## وضعیت
آکادمی پرچم یک محصول در **واحد آموزش و توسعه، معاونت سرمایه انسانی** است و معاونت مستقل مدیرعامل نیست.

تمرکز اجرایی فعلی آکادمی: **تربیت مدیر محصول**.

## تعریف کوتاه
پرچم یک آموزشگاه صرف نیست؛ یک **سیستم شناسایی، پرورش، آزمون و اثبات رهبران** است.

خروجی اصلی پرچم «فارغ‌التحصیل» نیست؛ **پرچمدار** است: فردی که شایستگی پذیرفتن یک مأموریت واقعی را در عمل اثبات کرده است.

> پرچم داده نمی‌شود؛ به دست می‌آید.
